# Правила проекта

- При каждом коммите **обязательно** повышать версию проекта в файле `src/MemPulse/MemPulse.csproj`. Это обеспечивает корректную работу автопубликаций и позволяет CI‑pipeline правильно определять новые релизы.
- Версия должна быть увеличена **по патч‑номеру** (меньший шаг, чем мажор/минор). Пример: `0.2.16 → 0.2.17`.
- При изменении версии обновлять также файл `README.md`, если в нём указана текущая версия.
- При несоответствии версии и коммита CI‑pipeline будет падать с ошибкой `VersionMismatch`. 
- Любое изменение файлов должно быть зафиксировано локальным коммитом перед любыми другими действиями (push, merge и т.д.).
