# Правила работы над MemPulse

## Ветвление и внесение изменений

- Работаем **исключительно в ветке `main`**.
- **Не создаём новые ветки** ни для разработки функций, ни для исправлений, ни для дизайна, ни для экспериментов.
- Все разрешённые изменения вносим и коммитим **напрямую в `main`**.
- Не используем pull request из отдельной ветки как стандартный способ внесения изменений.
- Перед изменением файлов проверяем, что целевая ветка — `main`, и используем актуальную версию файлов.

Эти правила обязательны для всех дальнейших задач по репозиторию MemPulse.
